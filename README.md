# 🔐 PrivacyGuard – Smart Privacy Management System for Online Social Networks

PrivacyGuard is a secure privacy management module developed as part of the **Holistic Cybersecurity Approach for Online Social Networks**. The system empowers users with granular control over their personal data, provides real-time privacy transparency, and monitors third-party application access to ensure a safer and more trustworthy social networking experience.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/mrSinghSatyam/PrivacyGuard_Frontend.git
```

---

## Install Backend

```bash
cd server
npm install
```

Create a `.env` file

```env
PORT=5000

MONGO_URI=your_mongodb_uri

JWT_SECRET=your_secret_key
```

Run Backend

```bash
npm run dev
```

---

## Install Frontend

```bash
cd client

npm install

npm run dev
```

# 📡 API Endpoints

| Method | Endpoint | Description |
|---------|----------|-------------|
| POST | /api/auth/register | User Registration |
| POST | /api/auth/login | User Login |
| GET | /api/privacy | Privacy Settings |
| POST | /api/privacy | Update Privacy Settings |
| GET | /api/consent | View User Consents |
| POST | /api/consent | Grant Consent |
| DELETE | /api/consent/:id | Revoke Consent |
| GET | /api/audit | View Data Access Logs |
| GET | /api/integrations | Third-Party Applications |
